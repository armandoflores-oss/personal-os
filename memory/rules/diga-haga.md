# Cuando le diga a Armando que NO haga algo y a la vez que SÍ haga una variante, s

Y siempre dar la ubicación exacta de cualquier archivo que mencione (correo + asunto + fecha, o ruta), nunca solo el nombre.  <!-- feedback:correction -->
